Script integrity (SRI) helper

Open this page once (it must be served over https, for example from your GitHub Pages site, or opened on a computer). It downloads each script, works out its SHA-384 fingerprint, and gives you ready-to-paste <script> tags. After you paste them into index.html and admin.html, the browser refuses to run a script if the file ever changes. Delete this page afterwards.

One script address per line. To use a newer version, change the version number in the address first, then test the site.
